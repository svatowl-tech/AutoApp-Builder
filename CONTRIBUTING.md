# Руководство по участию в разработке (Contributing to AutoApp-Builder)

Спасибо за интерес к проекту **AutoApp-Builder**!
В настоящий момент приложение находится на **ранней стадии разработки (`Early Stage / Alpha v0.1.0-alpha.1`)**, поэтому мы особенно приветствуем баг-репорты, предложения по улучшению детектора стеков (`detector.ts`) и рецептов автоисправления (`process-logger.ts` / `healer.ts`).

---

## Как сообщить об ошибке (Bug Report) с полным логом процессов

В **AutoApp-Builder** встроена система сквозного логирования всех дочерних процессов ОС и IPC/HTTP вызовов:
1. Нажмите кнопку **«ЛОГ ПРОЦЕССОВ»** в правом нижнем углу приложения.
2. Попробуйте применить встроенную кнопку **автоисправления ошибки**.
3. Нажмите кнопку **«СКАЧАТЬ .LOG»** в верхней части панели диагностики — приложение выгрузит файл `AutoApp-Process-Telemetry.log` со всеми кодами возврата, командами, `PID` и стеками вызовов.
4. Создайте новую задачу в разделе **GitHub Issues** и приложите выгруженный файл `.log`.

---

## Требования к коду при отправке Pull Request

1. **Кроссплатформенность**: используйте исключительно `path.join()` и `path.resolve()`, не хардкодьте платформозависимые пути (`C:\` или `/tmp`).
2. **Строгая типизация**: перед отправкой PR обязательно выполните:
   ```bash
   npm run lint
   npm run build:electron
   ```
3. **Никаких платных облачных ИИ-сервисов**: проект использует исключительно локальные модели (до 3B параметров) и детерминированные алгоритмы диагностики.
