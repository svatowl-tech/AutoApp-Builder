# Changelog

Все заметные изменения в публичном проекте **AutoApp-Builder** документируются в этом файле.
Проект придерживается семантического версионирования ([SemVer](https://semver.org/lang/ru/)).

---

## [0.1.0-alpha.1] — 2026-11-11 (Early Stage / Public Alpha Pre-Release)

> **⚠️ Статус релиза: Ранняя стадия разработки (Early Stage Alpha)**
> Первый публичный пре-релиз кроссплатформенного оркестратора AutoApp-Builder с автоматической матричной сборкой через GitHub Actions под Windows, macOS и Linux.

### Добавлено
- **Хаб собранных приложений (`APPS HUB`)**: стартовый экран управления всеми скомпилированными проектами с прямым запуском/остановкой процессов из интерфейса, мониторингом живого `PID`, аптайма и консоли `stdout`/`stderr`.
- **Система проверки и автообновления GitHub-проектов**: ручной и фоновый опрос коммитов через GitHub REST API с автоматической пересборкой и сохранением предыдущей рабочей версии для мгновенного отката (**1-Click Rollback**).
- **Конвейер максимальной бинаризации (`Executable-First`)**: поддержка упаковки веб-проектов (`React`, `Vite`, `Node.js`), `Python` (`PyInstaller`), `Rust` (`Cargo`) и `Go` в автономные десктопные исполняемые файлы (`.exe`, `.dmg`, `.AppImage`) и пакеты **Android (`.apk`)**.
- **Бесплатный локальный ИИ-движок самоисцеления (`ErrorHealer`)**: рекурсивное исправление ошибок сборки (до 4 попыток) через локальные модели до 3B параметров (`Qwen 2.5 Coder`, `Llama 3.2`, `SmolLM2`) в режимах `builtin-llama`, `ollama`, `local-server` и `custom-openai`.
- **Единый централизованный кэш (`SharedCacheManager`)**: консолидация кэшей `npm`, `pip`, `Gradle` и `Cargo` с мониторингом диска и автоматической очисткой по алгоритму LRU.
- **Сквозное логирование всех процессов (`SystemProcessLogger`) и Auto-Remediation**: запись всех дочерних процессов ОС и вызовов API в `autoapp-system.log` и `process-journal.jsonl` с автоматической диагностикой первопричин и кнопками исправления ошибок в 1 клик.
- **Матричный CI/CD пайплайн (`.github/workflows/build.yml`)**: автоматическая сборка и публикация Pre-Release артефактов для Windows, macOS и Linux в публичном репозитории GitHub.
